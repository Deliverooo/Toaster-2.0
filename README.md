# Toaster 2.0
Toaster Engine v2.0 (the definitive edition)

A graphics engine based on the OG Toaster architecture, but with better things...
At the moment, for simplicity, I have decided to limit the engine to only support 2D rendering. This is also one of the reasons that I stopped working on the original Toaster, that being 3D rendering was too difficult to maintain.
Despite this I still may consider adding basic mesh loading in the future, but as it is now, I will stick to two dimentions.

My plans for the enigne are as follows:
- Texture loading system
- C# scripting (I have no idea how to do ts...)
- ¿Video loading? (possibly; it sounds cool...)
- Other things
